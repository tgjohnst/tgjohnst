### 👨‍💻 About Me

I build systems at the intersection of Cloud Architecture, Computational Biology, and Data Science. I really enjoy solving tricky algorithmic puzzles to help accelerate scientific discovery. From architecting complex cloud systems from scratch, to engineering robust pipelines for NGS data, my goal is to build the tools that make science happen. 

I've increasingly found satisfaction building, fixing, and automating the behind-the-scenes pieces of computational science, which many find tedious. **If I can jump in and fix in ten minutes what would take someone else a week, I've done my job.**
